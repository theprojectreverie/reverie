REVERIE — BATTLE UI VISUAL ASSETS
=================================

This archive contains individually cropped PNG visuals from the generated battle-interface concept sheet.

Folders:
- backgrounds/: four battle-scene environment images
- buttons/: Attack, Skill, Ultimate, Item, Defend, End Turn
- panels/: dialogue, portrait, status, battle log, character and boss panels
- meters/: HP/energy and resource meters
- skills/ and icons/: skill/status icons and turn-order track
- controls/: Auto, speed, pause and settings controls
- banners/, branding/, decorative/: supporting visual elements

Important production note:
These are isolated crops from a concept sheet, not final pixel-perfect sprite exports. Some crops intentionally group related small elements, and a few edges may need cleanup or tighter slicing before in-game use. The source reference sheet is included for comparison. No generic code-drawn UI is included.
