REVERIE — FIVE BIOME TRANSITION ART ASSETS
These are transparent-background, wide decorative isometric strips.
1 Royal Gardens → Royal Gate
2 Royal Gate → Willow Fields
3 Willow Fields → Elderwood Grove
4 Elderwood Grove → Forsaken Ruins
5 Forsaken Ruins → Ruined Tower

IMPORTANT: Art is a visual prototype, NOT collision-ready 32x32 tiles.
Do not place across an existing walkable path or overwrite current ground.
Import as separate editor Sprite2D nodes with z_index behind playable terrain, then verify scale, route, collision and alignment in Godot.
Sprites have no collisions. Each strip should be positioned and scaled independently.
